# heroine-cinema-lp v20

高クリック率を狙う「長いLP＋どこまでも追いかける追従CTA」版です。

## 考え方
- ファーストビューだけで押してもらうつもりで作り、押さなかった人には「幕」ごとに何度でも押す理由を用意する
- 8つの幕（第一幕〜第七幕と終幕）は、それぞれ「幕のタイトル → シーン → 問いかけ＋ボタン」で一つの波になっている
- 画像の下に映画の字幕のような問いかけを入れ、疑問形と感情のコピーでたたみかける
- 行き先は Amazon の出品一覧ひとつだけ（ヘッダーのリンクなど、脇道はなし）

## まず編集する場所
1. `js/media-config.js` の `amazonListUrl` に出品一覧の URL を入れる（https:// で始まるもののみ有効）
2. 写真を各フォルダーに連番で追加し、`js/media-config.js` の `count` を合わせる（下の「写真」を参照）
3. 文言は `index.html`、色や余白は `css/style.css` の先頭の変数

## 写真（ページを開くたびにランダム）
| フォルダー | 比率 | サイズ | 使われる場所 | 最低枚数 |
|---|---|---|---|---|
| `images/hero/` | 4:5 | 1080×1350 | ファーストビュー（PC・スマホ共通） | 2 |
| `images/wide-landscape/` | 16:9 | 1920×1080 | PC の山場・横長の 6 か所 | 6 |
| `images/wide-portrait/` | 4:5 | 1080×1350 | PC の山場・縦長の 2 か所（第四幕・第六幕）／スマホの山場 8 か所 | 8 |
| `images/scene-pc/` | 16:9 | 1920×1080 | PC の左右交互のシーン 41 か所 | 41 |
| `images/scene-sp/` | 4:5 | 1080×1350 | スマホの左右交互のシーン 41 か所＋作品の棚 6 枚（PC・スマホ共通） | 47 |

- ファイル名は「フォルダー名-番号.webp」（例 `scene-pc-001.webp`）。番号は 001 から抜けなく連番に
- 写真を増やすときは、ファイルを追加して `js/media-config.js` の `count` を変えるだけ
- 1 回の表示で、同じフォルダーの写真を 2 回使いません（最低枚数より少ないときだけ繰り返します）
- ファーストビューには、前回開いたときと同じ写真が続けて出ないようにしています
- wide-landscape は左下に文字が重なるので、人物が右寄りの写真を。scene の 2 つは下 4 分の 1 に字幕が乗ります
- JavaScript が使えない環境では、番号順の写真が表示されます

映画のスチル写真や他人の写真は、著作権・肖像権の許可がないと使えません。許可済みの写真だけを使ってください。

## 安全性について
- `index.html` に Content-Security-Policy を設定しています。外部の怪しいスクリプトは読み込まれません
- 行き先 URL と画像の URL は、https か同じフォルダ内のファイルだけを受け付けます（javascript: などは無視）
- 動画は使わない方針のため、動画の読み込みは CSP で禁止しています
- 今後 Google アナリティクスやタグマネージャーを入れるときは、CSP の `script-src` と `connect-src` にそのドメインを追加してください

## 計測について
ボタンにはそれぞれ `data-cta`（hero / wave-1〜5 / final / sticky）が付いています。
Google タグマネージャーを入れると `lp_cta_click` イベントで「どのボタンが押されたか」が分かります。
ファーストビューにどの写真が出たかは `lp_hero_image`（image に写真の番号）で分かります。

## WordPress で使うとき
写真をサーバーの別の場所に置く場合は、`js/media-config.js` の各フォルダーの `path` を https:// で始まるフォルダーの URL（最後に / を付ける）に変えてください。ファイル名は連番のままにしておく必要があります。
